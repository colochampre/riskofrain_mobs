# Contributing to Risk of Rain Mobs

Thank you for your interest in contributing to Risk of Rain Mobs! We appreciate your time and effort. By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## 🚀 Getting Started

1. **Open an issue** to discuss the changes you'd like to make
2. **Fork** the repository
3. **Clone** your fork locally
4. **Create a branch** for your changes
5. **Commit** your changes with descriptive messages
6. **Push** to your fork
7. **Open a Pull Request**

## 📝 Code Guidelines

- Follow the [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html)
- Use descriptive names for variables, methods, and classes
- Document your code with comments when necessary
- Keep classes small and focused on a single responsibility
- Write unit tests for new features

## 🧪 Pull Request Process

1. Ensure your code builds successfully (`./gradlew build`)
2. Verify there are no style errors (`./gradlew checkstyleMain`)
3. Update relevant documentation (README, comments, etc.)
4. Make sure all tests pass
5. Describe your changes in the PR clearly and concisely

## 🐛 Bug Reports

When reporting a bug, please include:
- Minecraft version
- Mod version
- Steps to reproduce the bug
- Error logs (if applicable)
- Screenshots (if they help illustrate the issue)

## 💡 Feature Requests

To request a new feature:
1. Check that there isn't already an open issue for that feature
2. Describe the feature in detail
3. Explain why it would be useful for the community
4. If possible, propose an implementation

## 📜 Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By participating, you are expected to uphold this code.
